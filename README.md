**Raqeeb** (رقيب - Arabic for "Observer") is a modern, modular **web security observation and vulnerability assessment platform** built with **.NET 10** and designed using **Clean Architecture**.

Raqeeb focuses on **safe, ethical, and authorized security testing**, providing structured insight into common web security risks without destructive or exploitative behavior.

## 🔍 What is Raqeeb?

Raqeeb helps developers and security teams:

- Observe the security posture of web applications
- Detect common vulnerabilities (OWASP-aligned)
- Run modular, job-based security scans
- Work with a clean API-first backend
- Use a professional, localized dashboard (English / العربية)

> ⚠️ Raqeeb must only be used on systems you own or have explicit permission to test.

---

## 🧱 Architecture Overview

Raqeeb follows **Clean Architecture**:

```
Domain → Application → Infrastructure → Presentation (Web/API)
```

Key principles:
- API-first (no MVC views)
- Strong separation of concerns
- Modular and extensible scanning engine
- Async and background job execution
- Localization-ready by design
